# 異星蟻國 · Prototype 0.6.4.1

第一關是有邊界的 RTS 戰役：發展王巢、探索與防守，找出並攻破近鄰、獵殺、甲殼與深林四個敵對蟻國；四隻敵方蟻后全部死亡才獲勝，己方蟻后死亡則失敗。沿用現有的蟻群模擬與功能巢，不需安裝套件或建置。

## 啟動

```sh
node server.cjs
```

伺服器預設監聽 `0.0.0.0:4173`。在本機開啟 http://127.0.0.1:4173/；同一區網可使用電腦的 IPv4 位址與相同連接埠。也能直接開啟 `index.html`，但建議使用 HTTP，讓存檔來源保持一致。

開啟後遊戲暫停，按 1×／3× 開始。每 15 秒自動儲存；設定內可手動儲存或建立新巢。舊版本存檔會遷移至 0.6.4.1；沒有離線快轉。`?test=1` 使用獨立測試存檔。

## 直接操作

| 目的 | 操作 |
| --- | --- |
| 指揮 | 左鍵點蟻群或拖框選取 → 點空地移動、點未知地帶探索、點敵人或活昆蟲進攻；右鍵不下令 |
| 多兵力 | 再點附近友軍可加入選取；選取不開啟阻擋地圖的大面板 |
| 育幼 | 點幼體或正式育幼巢，查看照護狀態；食物、添加物、濕度與培育方向點選後立即套用，正常成長全程自動 |
| 採集 | 選取工蟻後點食物直接採集；安全、已知的普通食物也會由 AI 自行調度 |
| 建設 | 點地下通道提出六種功能需求，再選左側、右側、深層、核心或巢口方向；蟻群自行開路、挖空腔與塑形 |
| 擴巢 | 點已知地下通道 → 擴建巢穴 → 選大方向或擴大空腔；工蟻會自行持續施工 |
| 探索 | 地表與地下有固定戰役邊界；地表為正俯視，含簡單高度與攀爬路徑 |
| 狩獵 | 活昆蟲先接戰，死亡後轉成可搬運的昆蟲屍體 |
| 防守 | 巢口與通道可派守衛、縮窄、封閉與重開；狹道限制同時接戰數量 |
| 資料 | 「蟻群」查看即時工蟻調度、兵蟻、幼體與巢室；點巢室可直接定位，並可設定王巢優先發展方向 |

地圖可拖曳、滾輪或雙指縮放。主頁不捲動，情境面板與資料視窗可在內部捲動。工蟻會處理近距離威脅與有限援戰，但保留玩家下達的主任務；搬運、施工、探索、重傷撤退與明確命令不會被普通自動工作任意覆蓋。

## 王巢建設與軍事育成

- 育幼巢、儲食巢、獵物處理巢、休養巢、軍事育成巢、異變巢都占用真實地下空間，並以有機形狀直接顯示在地圖中。
- 提升功能巢能力時，工蟻會自行挖開周邊；原地不適合時會規劃另一座同類巢室，不再要求玩家猜尺寸與距離。
- 第一座正式育幼巢完成後，工蟻自動遷移所有幼體，原臨時育幼區退回普通空腔。
- 選取蟻群後直接在地圖下移動、攻擊、採集或挖掘命令；建設由獨立按鈕開啟。
- 左、右、下方向開挖是持續工程。工程遇到緊急事件可暫停，但會保留並在可用工蟻回來後續工。
- 每個資源點保有獨立派工；少量、一半、大量與自動會立即回報實際派遣或等待人數。
- 六種功能巢會顯示各自的幼體、庫存、獵物處理、恢復、軍事培育或異變資料。
- 大型獵物經獵物處理巢拆解成食物、高蛋白、甲殼材料與特殊組織。儲食巢提高容量，休養巢會自動加快傷兵恢復。
- 普通兵蟻、重甲兵蟻、巨顎兵蟻與吐酸兵蟻從育幼設定與對應巢室中羽化，和工蟻分開統計；特殊個體仍是低機率的個體差異。
- 軍事育成巢完成後會逐步讓新幼體培育普通兵蟻；玩家仍可在育幼巢直接調整特定批次。新王室完成後蟻后遷入，附近待命蟻會集結護衛。
- 初生蟻巢、主巢、王巢、深層王巢與蟻都由人口、可用巢室、地下空間、深度與領土自然形成，沒有手動升級。

## 第一關世界

- 地表與地下以有限的小區塊延伸；世界邊界會阻止無限探索和施工。
- 挖掘方向代表趨勢，通道會彎曲、出現寬窄差異、繞過硬層並在重要發現時停止。
- 食物耗盡後，採集蟻會先回巢，再轉往已知安全來源或待命，不會自行探索未知地圖。
- 受傷工蟻移動、搬運與戰鬥能力下降；重傷時優先脫離並回巢消耗少量食物休養。
- 四個敵對蟻國有各自的蟻后、人口、食物、育幼、兵力與攻守節奏；覆滅其中一國不會停止其他敵國的活動。
- 最後一隻敵方蟻后死亡後第一關勝利，遊戲時間停止；己方蟻后死亡則失敗。兩種結局都能重新開始。
- 人口、深層巢路、首次大型狩獵、敵巢瓦解與黑色未知物以短暫可定位推播留下里程碑。
