# ART_DIRECTION｜V7.2 遊戲內修正

## 使用者實際驗收後的五項修正
1. 上方工蟻／兵蟻／食物／敵國／幼體：改為純文字＋數字，不用圖示。
2. 蟻后與螞蟻：從簡單 SVG／卡通圖案改成有甲殼體積、分節、光影的正式 raster sprite。
3. 探索／事件面板：取消大框內再疊大型裝飾框；只保留單一清楚主框，文字與按鈕不得被裝飾層遮住。
4. 巢穴與地表：從平面管理圖改成「世界場景」。地下要看得到土壁、根系、腔室、菌光與深度；地表要看得到森林土壤、根木、植物、岩塊與光影。
5. 手機長按框選：必須由遊戲接管，不得再觸發網頁文字反白／複製選單。

## 風格
- 與主選單／片頭同一世界。
- 黑褐、焦土橙、琥珀、煙灰、低飽和森林綠。
- 可以不是照片寫實，但不能 Q 版、icon 化、卡通化。
- 蟻族必須保留螞蟻解剖：頭／胸／腹、六足、觸角、顎、甲殼分節。
