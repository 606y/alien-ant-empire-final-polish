# ART_DIRECTION｜V8 場景化世界重構

V8 的核心不是「把圖示畫漂亮」，而是把 Prototype 的平面圖板重構成可辨識的 2.5D 蟻族世界。

## 地下
- 必須像真正地下蟻巢：土壁、腔室、橋道、根系、菌光、琥珀、搬運線。
- 功能巢是物理房間，不是符號。
- 單位腳下有接地陰影；角色與土層明度分離。

## 地表
- 必須像真正森林地表：泥土、苔蘚、樹根、倒木、石塊、葉片、蘑菇、水、資源。
- 種子／昆蟲／樹脂／岩礦等都是場景物件，不是貼在地面上的 icon。
- Camera 拖曳時整個世界一起移動；不得露出黑條。
- 未探索區是暗化森林／霧，而不是空白黑底。

## 單位
- 己方 1 國＋敵方 4 國，各自具有輪廓差異。
- 兵種外觀跟功能一致。
- 蟻后是獨立王族體型，不是普通螞蟻放大。

## UI
- UI 只輔助世界，不主導畫面。
- 上方資源列用文字＋數字，不用難懂小圖示。
- Context panel 單框、正常文件流，禁止框中框壓文字。
