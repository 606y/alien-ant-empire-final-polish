# V8｜功能巢與進化

正式功能巢不是 UI 圖示，而是遊戲世界中的物理巢室。

| 功能巢 | Lv1 | Lv2 | Lv3 |
|---|---|---|---|
| 育幼巢 | 小量卵／幼體 | 分區育幼、更多照護位 | 大型育幼室、密集卵蛹與照護區 |
| 糧倉 | 小型食物堆 | 分類儲存 | 大型多層儲存與運輸動線 |
| 獵物巢 | 小型獵物處理區 | 分解／儲備擴張 | 大型獵物處理與甲殼堆 |
| 休養巢 | 小型菌床 | 更多菌光與休息位 | 完整休養腔室與多區巢床 |
| 兵巢 | 小型集結區 | 甲殼／防禦結構增加 | 大型軍事巢、集結與武裝感 |
| 異變巢 | 少量樹脂／異質物 | 菌絲與異變結晶擴張 | 大型異變器官／琥珀核心 |
| 王巢 | 基礎王室空間 | 護衛、卵與王室光源增加 | 完整女王王座與帝國核心 |

正式素材：`rooms/<type>_lv1_v8.png` ～ `lv3`。
