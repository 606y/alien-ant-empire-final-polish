# V6 Copy Deck

## 主選單副標語
在黑暗森林中，孕育一座會呼吸、擴張並吞噬一切的異變蟻國。

## 片頭三幕文案

### 第一幕｜墜落
標題：森林深處的異物
內文：數百年前，一艘不屬於這個世界的飛行器墜入森林深處。殘骸被泥土與根系吞沒，異質物質卻開始緩慢滲入大地。
按鈕：繼續

### 第二幕｜異變
標題：琥珀聖殿中的蟻群升蛹
內文：受污染的土壤改變了巢穴，也改變了族群。甲殼更堅硬，兵種更分化，王國從黑暗中學會組織、繁衍與戰鬥。
按鈕：繼續

### 第三幕｜蟻國
標題：黃昏戰場上的蟻國對決
內文：如今四方勢力盤據森林，蟻巢不再只是巢穴，而是一個會擴張、會征服、也會被戰火吞噬的帝國。
按鈕：進入蟻國
