# 《異星蟻國》Assets v4 正式文案

## 主選單副標語
在黑暗森林中，孕育一座會呼吸、擴張並吞噬一切的異變蟻國。

## 第一幕｜墜落
小標：墜落
標題：森林深處的異物

數百年前，一艘不屬於這個世界的飛行器墜入森林深處。
烈焰撕開大地，殘骸沉入根系與泥土之下。
真正留下來的，卻不是金屬，而是會改變生命的異質物質。

按鈕：繼續

## 第二幕｜異變
小標：異變
標題：蟻群不再只是蟻群

污染沿著土壤、菌絲與地下水蔓延。
一代又一代，巨顎、重甲、翼化與未知器官開始出現。
原本微小的族群，逐漸成為另一種生命。

按鈕：繼續

## 第三幕｜蟻國
小標：蟻國
標題：戰爭已經開始

四個敵對蟻國早已佔據森林。
牠們爭奪食物、巢穴、通道與領地，也吞噬彼此的未來。
而現在，第五座王國在戰火中甦醒。

按鈕：進入蟻國
