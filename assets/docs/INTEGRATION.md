# Assets v5 整合指引

## 主選單目標
- 主選單使用 **蟻國交戰** 的大場面背景，不要再用遠景靜態飛蟻當主要動態來源。
- 只保留三個明確的動態焦點：
  1. 左下近景／靠近「建立新蟻國」按鈕旁的 **持旗兵蟻背影**。
  2. 右側近景的 **厚甲重裝敵兵**。
  3. 天空中的 **單一主飛蟻**。
- 其餘兵種、飛蟻交戰、燃燒建築、墜落飛蟻等都保留在背景畫面中，不需要程式逐一做活化。

## 動畫要求
- **flag_ant_v5.png**：只讓旗布飄動；旗杆與角色本體穩定。
- **heavy_enemy_v5.png**：武器動作要明顯，不要只是輕微抖動；建議做蓄力→揮擊→回位的循環。
- **flyer_body_v5.png + flyer_wings_v5.png**：翅膀獨立振動，身體緩慢巡航；避免蒼蠅感。
- 不要再切片扭曲背景，也不要從背景裡裁切靜止角色去做假動態。

## 版面要求
- 背景仍為 16:9。
- 左側文字區保持可讀，但不要半屏死黑。
- 角色比例需符合遠景城市尺度，不能過大。
- 不要加入巨大雕像。

## 片頭要求
- 三張片頭圖直接使用 v5 圖片。
- 只做極慢縮放、輕微平移、淡入淡出。
- 不要再使用低解析模糊效果。
