# 《異星蟻國》V6.1 接入規格

## 1. 本輪只做兩件事

### A. V6 主選單位置微調
不要重畫、不要裁切、不要改角色造型。

依 `placement_v6_1.json`：
- 桌面 1366×768：持旗兵整組上移 92px；厚甲整組上移 82px。
- 手機 390×844：持旗兵整組上移 68px；厚甲整組上移 62px。
- X 位置與目前 V6 保持不變。
- 尺寸與目前 V6 保持不變。
- 持旗兵的旗布動畫完全保留目前 V6 版本。
- 厚甲這輪維持完整靜態姿勢，不拆武器、不做局部旋轉，避免再次出現武器像要斷掉的問題。

## 2. 正式 10 秒電影片頭
影片：`video/intro_cinematic_v6_10s.mp4`
Poster：`video/intro_cinematic_v6_poster.jpg`

正式流程：
`主選單 → 玩家按「建立新蟻國」 → 10秒電影片頭 → 現有 V6 三幕敘事 → 正式進入遊戲`

影片由 ChatGPT 已完成美術、動態與聲音設計。Codex 不得重製影片內容，只負責播放與流程串接。

### 播放規格
- HTML `<video>` 或等效原生播放方式。
- `playsinline`。
- 不循環。
- 保持 16:9，黑邊優先於拉伸。
- 有聲播放需遵守瀏覽器使用者互動限制；因影片是由「建立新蟻國」按鈕觸發，應以該次互動啟動播放。
- 提供右上角或右下角「跳過片頭」。
- 跳過或影片播放完畢後，都進入現有 V6 三幕敘事，不直接進遊戲。
- 不要再對影片套 blur、zoom、filter、Canvas 變形或額外粒子。

### 重新觀看
主選單可新增「觀看片頭」入口，但只做 UI/流程，不重製影片。若本輪不想新增按鈕，可留待下一輪。

## 3. 音訊
影片已內嵌正式聲音設計。影片播放期間：
- 暫停／淡出主選單 BGM，避免雙重音訊。
- 影片結束後再進三幕敘事原本的音訊流程。
- 全域「聲音：關」時，影片以 muted 播放。

## 4. 禁止事項
- 不自行設計或重畫片頭。
- 不重新生成影片。
- 不把三幕敘事刪掉。
- 不讓電影片頭播放完直接跳過三幕。
- 不修改 `engine.js`、`world.js`、`interaction.js` 或 Prototype 0.6.4.1 核心玩法。
