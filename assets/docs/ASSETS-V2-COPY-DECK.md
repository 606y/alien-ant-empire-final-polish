在黑暗森林中，孕育一座會呼吸、擴張並吞噬一切的異變蟻國。

## 片頭第一幕
小標：墜落
標題：森林深處的異物

數百年前，一艘不屬於這個世界的飛行器墜入森林深處。
殘骸被泥土與根系吞沒，異質物質卻開始緩慢滲入大地。

按鈕：繼續

小標：異變
標題：蟻群開始改變

一代又一代，受到污染的蟻群產生分化。
巨顎、重甲、翼化與未知特徵逐漸出現——
原本渺小的族群，開始走向另一種生命。

按鈕：繼續

標題：森林從來不是無主之地
