# 《異星蟻國》Assets v3 正式文案

## 主選單副標語
在黑暗森林中，孕育一座會呼吸、擴張並吞噬一切的異變蟻國。

## 第一幕｜墜落
小標：墜落
標題：森林深處的異物

數百年前，一艘不屬於這個世界的飛行器墜入森林深處。
殘骸被泥土與根系吞沒，異質物質卻沒有消失。
它沿著地下水、菌絲與根脈，緩慢滲入整片森林。

按鈕：繼續

## 第二幕｜異變
小標：異變
標題：蟻群不再只是蟻群

污染沒有帶來瞬間的奇蹟，而是在世代之間留下痕跡。
巨顎、重甲、翼化與未知器官逐漸出現。
微小的族群，開始長成不屬於自然秩序的生命。

按鈕：繼續

## 第三幕｜蟻國
小標：蟻國
標題：森林從來不是無主之地

四個敵對蟻國早已在森林中擴張。
牠們爭奪食物、巢穴、通道與領地，也吞噬彼此的未來。
現在，第五座王國開始甦醒。

按鈕：進入蟻國
